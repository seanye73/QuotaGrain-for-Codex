How to install QuotaGrain for Codex

  1. Download the DMG installer using the button above.
  2. Open the DMG and drag QuotaGrain for Codex into Applications.
  3. Open QuotaGrain for Codex from Applications, then eject the installation disk.
  4. Use its menu bar icon to add an account, sign in, and view quota and reset times.

After installation

Add accounts from the menu bar to view quota and reset times. For external API accounts, enter your service endpoint and model.
