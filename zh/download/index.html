如何安装 QuotaGrain for Codex

  1. 点击上方按钮下载 DMG 安装包。
  2. 打开 DMG，将 QuotaGrain for Codex 拖入“应用程序”。
  3. 从“应用程序”打开 QuotaGrain for Codex，然后推出安装磁盘。
  4. 通过菜单栏图标添加账号、登录，并查看额度与重置时间。

安装后开始使用

安装后，从菜单栏添加账号，查看额度与重置时间；外部 API 账号可填写服务地址和模型。
