常见问题

你可能还想知道。

QuotaGrain for Codex 是 Codex 官方产品吗？+

不是。QuotaGrain for Codex 是独立开发的第三方工具，与 OpenAI 无隶属或合作关系。

QuotaGrain for Codex 是什么，适合谁？+

QuotaGrain for Codex 适合同时使用多个 Codex 账号，或希望在独立 Codex 客户端中使用外部 API 和本地模型的 Mac 用户。它集中展示额度、重置时间和本地 Token 用量。

它也是 Codex 多开器吗？可以使用外部 API 吗？+

是的。除了查看额度，QuotaGrain for Codex 也能为不同账号打开各自独立的 Codex 客户端，让多个账号同时使用。你还可以配置外部 API 服务、API Key 和模型，在对应的 Codex 客户端中使用。外部服务需要兼容 OpenAI Responses 接口。

隔离出来的账号信息存在哪里？+

通过我们的软件新建的独立账号保存在你 Mac 的 ~/.codex/accounts/目录下。每个账号各有自己的配置、认证信息和会话数据，客户端数据保存在该账号目录下的 desktop/ 中。原有 ~/.codex 中的默认账号数据保持原样。

Codex 更新后，功能会受影响吗？+

可能会。QuotaGrain for Codex 依赖 Codex 与 macOS 的现有机制。上游变更或限制可能导致部分功能不可用。

免费版可以管理几个账号？+

最多 2 个，Codex 账号和外部 API 账号合计。免费版没有试用期限，包含自动刷新和额度提醒。

API Token 用量是否代表服务商余额？+

不是。外部 API 与本地模型的 Token 汇总来自本机用量记录，不代表服务商余额、剩余额度或账单金额。

使用 QuotaGrain for Codex 需要什么？+

需要 Apple Silicon Mac、macOS 13 或更高版本，以及用于登录和打开客户端的 Codex。外部 API 或本地模型服务需要兼容 OpenAI Responses 接口。
