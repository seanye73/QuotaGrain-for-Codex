QuotaGrain for Codex / Privacy

Privacy

QuotaGrain for Codex is a local-first macOS menu bar app. This page explains what it reads, stores, and sends to check quota, track usage, and unlock additional accounts.

01

Account quota checks

QuotaGrain for Codex reads the necessary authentication fields from each account’s local auth.json and makes read-only requests to ChatGPT’s quota and account endpoints to retrieve quota, reset times, and account display information. Authentication information is stored only on your Mac.

02

External API accounts

When discovering models, QuotaGrain for Codex sends your API key to your chosen provider’s /models endpoint. The provider handles these requests under its own privacy policy. API settings and credentials are stored in the corresponding Codex account folder. Credential files are restricted to your local user account.

If model discovery cannot confirm the selected model, refresh automatically sends small connection test requests to the same provider’s /responses endpoint. These requests may incur provider charges. They use only the fixed input Reply OK., allow up to 32 output tokens, and send no chat content or tools. They use stream=false and store=false; the provider’s privacy policy governs data retention. These tests are not included in the local token totals shown in the app.

03

Support and unlocking

Waffo handles payment on its hosted checkout. The author’s delivery service uses order details and the purchase email to verify payment and send a license key. This website does not collect payment information.

During activation and subsequent authorization checks, the app encrypts and sends the license key, device binding, computer name, model and OS version to the activation service to verify authorization status. Authorization is stored on your Mac; reading the saved authorization locally does not require a connection.

After saving a new authorization, the app also sends its SHA-256 digest to the same activation service to acknowledge local storage, retrying if necessary. This acknowledgement contains no account credentials or chat content.

04

Data stored on your Mac

Account records, settings, quota snapshots, and token totals stay on your Mac. Each account uses a separate Codex data directory. Codex stores session data in that account’s directory; QuotaGrain for Codex reads token counts for usage tracking and does not include chat content in its usage records.

Checking for app updates

When you check for updates, the app reads a public version manifest hosted on GitHub and compares versions locally. GitHub receives a normal network request, including your IP address. The app does not attach account credentials, license keys, device binding or usage data. A newer version offers a link to GitHub Releases; updates are not downloaded or installed automatically.

05

Reporting a problem

For help or feedback, email the developer with a brief description of what happened, your current app version (including the build number shown in About), and any relevant screenshots or supporting documents.
